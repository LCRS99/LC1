# RYM для Android

Лёгкая оболочка (WebView) вокруг сайта rateyourmusic.com с удобной мобильной навигацией.
Приложение неофициальное и не связано с RateYourMusic: оно просто открывает сам сайт,
ничего не парсит и не обходит.

## Что умеет

- Нижняя навигация: Главная, Чарты, Новинки, Жанры, Списки. Повторное нажатие на активную вкладку возвращает в начало раздела.
- Поиск в верхней панели.
- Кнопка «Назад» (и жест) ходит по истории страниц.
- Потянуть вниз, чтобы обновить страницу.
- Полоса загрузки и экран «нет сети» с кнопкой «Повторить».
- Ссылки на другие сайты открываются в браузере или нужном приложении, ссылки на rateyourmusic.com из других приложений открываются здесь.
- Меню: обновить, поделиться ссылкой, открыть в браузере, размер текста (100/115/130/85 %), выйти и очистить данные сайта.
- Тёмная тема следует за системной (внешний вид страниц сайта в тёмном режиме может быть неидеальным).
- Вход в аккаунт сохраняется между запусками (cookies).

## Как собрать

Нужны Android Studio (или JDK 17 и Android SDK 34).

**Через Android Studio:** File, Open, выберите папку проекта, дождитесь синхронизации Gradle, нажмите Run.

**Из командной строки:**

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Его можно установить на телефон,
разрешив установку из неизвестных источников.

Минимальная версия Android: 8.0 (API 26).

**Без установки Android Studio (облачная сборка на GitHub):**
загрузите проект в свой репозиторий на GitHub (ветка `main`). Во вкладке Actions
запустится «Build APK»; через 5–10 минут в завершённом запуске, в разделе Artifacts,
появится `rym-debug-apk`. Скачайте его, распакуйте и установите `app-debug.apk` на телефон.

## Если что-то поменяется на сайте

Все адреса разделов и поиска лежат в одном файле:
`app/src/main/java/com/example/rymclient/Config.kt`.

## Что не сделано

- Загрузка файлов через формы сайта (например, обложек) не поддерживается.
- Это оболочка, а не отдельный клиент: скорость и внешний вид страниц определяет сам сайт.
- Если сайт показывает проверку Cloudflare, пройдите её как обычно, она работает внутри приложения.
